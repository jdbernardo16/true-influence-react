# Retreat Page Implementation Plan

## Overview
Create a dedicated Retreat page that mirrors the structure and styling of the existing CoursePage, featuring a 3-day retreat agenda with detailed schedules, themes, and participant experiences.

## Design Patterns & Styling
Based on existing components, the Retreat page will follow:
- **Background**: `bg-[#1a1a4e]` (dark blue)
- **Text**: `text-[#faf8f5]` (light cream)
- **Accent**: `text-[#d4952a]` (gold)
- **Fonts**: Serif for headings, light font-weight for body text
- **Animations**: Framer Motion for scroll reveal, hover effects
- **Icons**: Lucide-react
- **Layout**: Responsive with mobile-first approach

## Component Breakdown

### 1. RetreatPage.tsx
Main page component that orchestrates all retreat sections
- Structure similar to CoursePage.tsx
- Wraps all sections in the dark blue background
- Includes Navigation component

### 2. RetreatHero.tsx
Hero section with:
- Background image with gradient overlay (opacity 30%)
- Title: "True Influence Retreat"
- Subtitle: "A Transformative 3-Day Experience"
- Description of the retreat experience
- Scroll indicator with animated chevron

### 3. RetreatOverviewSection.tsx
Overview of the retreat structure including:
- Title: "Retreat Structure"
- Description: "All levels, one container - This is a supportive working environment, not a passive experience"
- Grid of key features:
  - Focused work
  - Partner feedback sessions
  - Live application of training frameworks
  - Integration, connection and deep reflection
  - Private access (VIP dinner)
  - Stage with real evaluation
  - Advancement through scoring
  - Recognition and completion
- Accent note: "Everything leads to Stage Day"

### 4. RetreatDayScheduleSection.tsx
Day-by-day agenda breakdown with:
- Day 1: Arrival Day - "Break the Performance"
  - AM: Welcome, container setting, define work
  - PM: Story + message clarity, opening intentions, cohort meet-up
  - Dinner: Pod seating (Green, Blue, Orange, Purple)
- Day 2: Build + Refine Day - "Say It So It Lands"
  - AM: Pods story circle, full group discussion
  - PM: Self-advancement sessions, partner practice, pods live practice
  - Evening: VIP Dinner (private clients only)
  - Special feature: Relaxation Room (9am-8pm)
- Day 3: Promotion Day - "Be Seen and Celebrated"
  - AM: Pod expectations, final practice
  - PM: Stage Day (talks, QR code scoring, real-time feedback)
  - Closing: Awards, recognition, reflection circle

Design:
- Timeline or card-based layout
- Each day has its own visual section
- Color-coded day headers
- Schedule items with time slots
- Highlight VIP dinner and Stage Day

### 5. RetreatStagesSection.tsx
Details about Stage Day including:
- Stage Day explanation
- Qualification process (scoring system)
- Awards and recognition:
  - Top 3 appreciation awards
  - Peer kudos in app
  - Acknowledgment of growth and risk
- Closing Circle details

### 6. RetreatExperienceSection.tsx
What participants will experience:
- Focus on the "working environment" aspect
- Emphasize it's not passive
- Highlight peer feedback and real application
- Show the progression from focused work to stage performance

### 7. RetreatCtaSection.tsx
Call-to-action section with:
- Compelling CTA text about joining the retreat
- Button linking to contact/application form
- Optional testimonial or quote about the retreat experience

## Visual Elements to Incorporate

1. **Timeline/Progress Indicator**: Visual representation of the 3-day journey
2. **Icon System**: Use Lucide-react icons for each feature/activity
3. **Color Coding**:
   - Day 1: Soft green accents (arrival, setting intentions)
   - Day 2: Blue accents (building, refining)
   - Day 3: Gold accents (promotion, celebration)
4. **Card Layouts**: For sessions and activities
5. **Hover Effects**: On schedule items and feature cards
6. **Motion**: Scroll reveal animations for each section

## Content Mapping

From retreat.md → Components:
- "RETREAT STRUCTURE" → RetreatOverviewSection
- "DAY 1 – ARRIVAL DAY" → RetreatDayScheduleSection (Day 1)
- "DAY 2 – BUILD + REFINE DAY" → RetreatDayScheduleSection (Day 2)
- "DAY 3 – PROMOTION DAY" → RetreatDayScheduleSection (Day 3)
- "Stage Day" and "Qualification" → RetreatStagesSection
- "Awards + Recognition" → RetreatStagesSection
- "Closing Circle" → RetreatCtaSection or RetreatExperienceSection
