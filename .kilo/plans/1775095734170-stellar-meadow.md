# Course Page Implementation Plan

## Overview
Create a dedicated course page (`/course`) that presents the True Influence Method™ training program following the existing design system and visual patterns.

## Design System Analysis

### Current Theme Patterns
- **Primary Dark**: `#1a1a4e` (deep blue-purple)
- **Secondary Dark**: `#232360` (slightly lighter)
- **Accent Gold**: `#d4952a` (amber/gold)
- **Light Text**: `#faf8f5` (cream-white)
- **Alternating Backgrounds**: Sections alternate between dark colors for visual rhythm
- **Typography**: `font-serif` for headings, light/regular for body
- **Animations**: Framer Motion with staggered delays, viewport-based triggers
- **Components**: Cards with hover effects, timelines, accordions, grid layouts

## Page Structure

### 1. Hero Section
**Content**: Core Idea + Method Tagline
**Design**: Full viewport height, gradient background, logo mark
- Background image: `/carousel/img1.webp` with gradient overlay
- Main heading: "The True Influence Method™"
- Subheading: "The leadership path from self-doubt to global influence"
- Animated elements following HeroSection pattern
- Scroll indicator

### 2. Who This Is For Section
**Content**: Target audience + struggles
**Design**: Card-based grid on dark background
- Alternating cards showing "Who" and "Struggles"
- Target audience: "Accomplished women leaders: CEOs, founders, executives, creators, and public figures"
- Struggles list (5 items):
  - Lack of confidence speaking
  - Imposter syndrome
  - Lack of clarity around story
  - Feeling unsafe telling truth
  - Lack of clarity of unique value
- Visual: Use pattern from WhoSection with dark theme adaptation

### 3. Entry Offers Section
**Content**: Free lead magnet + Low-ticket offer
**Design**: Two-tier pricing cards
- **Card 1 (Free)**: "Discover the Truth Behind Your Story"
  - Description: Free video training
  - Icon: Play or Video icon
  - CTA: "Get Free Training"
- **Card 2 ($29)**: "What Is Your Million Dollar Message?"
  - Description: Breakthrough training for truth-telling
  - Price display: "$29"
  - Icon: Gift or Star icon
  - CTA: "Get Started - $29"
- Pattern adapted from CorporatePage pricing cards

### 4. Phase Journey Overview Section
**Content**: Visual timeline of 5 phases
**Design**: Vertical timeline similar to JourneySection
- Shows progression through all 5 phases
- Each phase shows:
  - Phase number (01-05)
  - Phase name (Tell Your Story, Move the Room, etc.)
  - Brief one-line goal
  - Level indicator (Beginner, Intermediate, Advanced, Legacy)
- Interactive: Click to expand phase details (scrolls to detailed section)
- Background: Alternating dark/light for contrast

### 5. Detailed Phases Section (Main Content)
**Content**: All 5 phases with Mastermind & Private Client options
**Design**: Vertical Accordion (chosen approach)

**Accordion Layout**:
- Each phase is a collapsible section
- Default: All phases collapsed, first phase open
- Click to expand/collapse individual phases
- Each expanded phase shows:
  - Phase header (name + level badge)
  - Goal, Problem, Solution sections
  - **Two pricing cards side-by-side (always visible)**: Mastermind | Private Client
  - Features list for each tier
- Visual: Similar to FaqSection but with complex content
- **Flexible entry**: Each phase has clear CTA for entry at that level

### 6. Phase Content Template (repeated for each phase)
**Structure**:
- Header: Phase number + Name + Level badge
- Goal Section: High-level objective
- Problem Section: Challenges addressed
- Solution Section: How the method solves it
- Pricing Cards Grid:
  - Left: Mastermind Experience
    - Price (large)
    - Features list (4-6 items)
    - CTA button
  - Right: Private Client Experience
    - Price (large, premium styling)
    - "Private advisory" badge
    - All mastermind features +
    - Additional private features (3-4 items)
    - CTA button

### 7. Testimonials Section
**Content**: Social proof for the transformation journey
**Design**: Carousel or grid of testimonials
- Testimonials can be phase-specific or overall journey testimonials
- Two layout options:
  - **Grid Layout** (recommended for phase-specific): 2-3 columns, each testimonial shows which phase it represents
  - **Carousel Layout** (recommended for journey testimonials): Horizontal scroll with testimonials
- Design pattern similar to TestimonialsSection
- Background: Dark section to maintain alternating rhythm
- Each testimonial includes:
  - Quote
  - Client name/title
  - Phase achieved (if applicable)
  - Optional: photo or initial avatar

### 8. End Results Summary Section
**Content**: Transformation across all phases
**Design**: Visual grid showing 5 end results
- Similar pattern to CorporatePage Results section
- Each result card shows phase outcome
- Brief description of transformation
- Background: Light section for contrast

### 9. Final CTA Section
**Content**: Call to action
**Design**: Centered, impactful
- Background: Gradient or image with overlay
- Heading: "Ready to Begin Your Journey?"
- Subtext: Choose your starting phase
- Two CTAs:
  - Primary: "Get Free Training" (links to entry offer)
  - Secondary: "Schedule Consultation" (links to contact)
- Pattern: Similar to CorporatePage CTA section

## Implementation Details

### Phase Data Structure
```typescript
interface PhaseOffer {
  price: string;
  name: string;
  features: string[];
  isPopular?: boolean;
  badge?: string;
}

interface Phase {
  id: number;
  name: string;
  level: string;
  goal: string;
  problem: string;
  solution: string[];
  endResult: string;
  mastermind: PhaseOffer;
  privateClient: PhaseOffer;
}

interface Testimonial {
  id: string;
  quote: string;
  author: string;
  title: string;
  phase?: number; // Optional: specific phase achieved
  image?: string; // Optional: client photo
}
```

### Interaction Design
1. **Phase Journey Timeline**: Clicking a phase scrolls to and opens its detail section
2. **Accordion**: Smooth expand/collapse with Framer Motion
3. **Pricing Cards**: Hover effects scaling up, button animations
4. **Mobile**: Stacked cards, simplified accordion

### Accessibility Considerations
- ARIA labels for interactive elements
- Keyboard navigation for accordion
- High contrast ratios maintained
- Semantic HTML structure
- Alt text for all images

### Responsive Breakpoints
- Mobile: < 768px - Stacked cards, simplified timeline
- Tablet: 768-1024px - 2-column grids
- Desktop: > 1024px - Full layouts, side-by-side pricing cards

## Best Practices & Recommendations

### Flexible Entry Pattern
- Each phase section includes a clear CTA to "Start at Phase X"
- Phase Journey Timeline links directly to phase details
- Entry Offers (Free + $29) positioned before detailed phases
- Pricing cards always visible to enable informed decisions

### Testimonials Integration
- Use existing TestimonialsSection patterns for consistency
- Testimonials can be:
  - Phase-specific (linked to particular transformation)
  - Journey-wide (overall transformation experience)
- Consider adding a "Filter by Phase" feature if many testimonials
- Mix of text and video testimonials if available

### Content Presentation
1. **Progressive Disclosure**: Start high-level, reveal details on interaction
2. **Visual Hierarchy**: Phase names → Goals → Pricing → Details
3. **Scannability**: Clear headings, bullet points, pricing visibility
4. **Journey Narrative**: Tell the story of transformation from phase 1-5

### UX Considerations
1. **Clear Entry Points**: Free offer and $29 offer prominently displayed
2. **Flexible Entry**: Allow users to start at any phase (not just Phase 1)
3. **Value Clarity**: Each phase should clearly articulate the transformation
4. **Social Proof**: Consider adding testimonials per phase (future enhancement)

### Performance
1. **Code Splitting**: Lazy load course page (not on critical path)
2. **Image Optimization**: Use existing optimized webp images
3. **Animation Performance**: Use GPU-accelerated transforms
4. **Bundle Size**: Phase data as constant, not fetched

### SEO Considerations
1. **Meta Tags**: Title, description for course page
2. **Structured Data**: Course schema markup
3. **Heading Structure**: Proper H1-H6 hierarchy
4. **Internal Links**: Link from homepage CorporateSection
